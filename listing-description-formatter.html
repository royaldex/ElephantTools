Description Tips for Etsy
First 160 characters appear in Google search previews — lead with the best hook
Use headers for sections: WHAT YOU GET, HOW IT WORKS, PLEASE NOTE
Etsy descriptions don't support markdown — use Unicode symbols for structure
Include file formats, dimensions, and technical details buyers need
Add care/usage instructions at the bottom — reduces support messages
