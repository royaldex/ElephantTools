💡 Pro Tips & Best Practices

✓
Etsy's 20MB limit applies to each individual file in a listing, not the total of all files.
✓
ZIP files must also be under 20MB — if you have multiple files, compress them efficiently.
✓
PNG files with large canvas sizes often exceed 20MB. Try converting to JPG or WebP.
✓
For font or SVG bundles that exceed 20MB, split them into multiple listings.
✓
High-resolution wall art at 300 DPI can easily exceed 20MB — check before listing.
✓
Use lossless PNG compression tools to reduce size without losing quality for digital art.
✓
Always check file size after any edits — adding a layer or increasing DPI can push it over.
